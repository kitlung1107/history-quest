# 冷戰・地下檔案嵌入維護

- 探索館分類：中五 → 冷戰世界。
- 任務資料：`client/src/content/tasks/s5-cold-war-maze.json`；CMS 的「歷史任務」可編輯。
- 固定遊戲網址：https://kitlung1107.github.io/ColdWarMaze/
- 遊戲保持於獨立 ColdWarMaze 儲存庫部署；探索館沒有複製 WASM、題庫或遊戲程式。
- 遊戲更新成功發佈到同一網址後，重新載入遊戲即可取得更新，毋須重新建置探索館。重新載入會重開本局，應先完成當前遊戲。
- 探索館任務內容或 CMS 資料修改仍需建置、發佈探索館。

## 學生操作

開啟任務並按「開始挑戰」，可在頁面內遊玩，或按「獨立開啟遊戲（新分頁）」。手機使用橫向，畫面太小時建議獨立開啟，再使用遊戲的全螢幕入口。遊戲內可用方向鍵、WASD 或觸控方向鍵移動。

## 成績範圍

目前只沿用探索館的網站快問記錄；該任務的分數及完成狀態表示已回答網站快問，不表示已完成迷宮或反映遊戲內答題表現。遊戲沒有接通探索館教師後台。獨立遊戲仍可能顯示原有 FORM 6 標籤，探索館按指定列為中五。

## 發佈

先審閱任務 JSON、TaskModal、CSS 及 CMS 設定，執行 `pnpm check`、`pnpm build`。本次修改只在本機；獲授權後才提交及推送至探索館的部署分支，待 GitHub Pages 工作流程成功後再從正式網站驗證入口及 iframe。

## 本機驗收

啟動 `pnpm dev --host 127.0.0.1` 後，開啟 `http://127.0.0.1:3000/?preview=student`（以啟動訊息的實際埠號為準）。這是開發模式現有的學生預覽入口。

選「中五」→「冷戰世界」，在《冷戰・地下檔案》卡片按「開始挑戰」，再於任務內按「開始挑戰」。確認遊戲出現主選單，進入迷宮後可移動角色；亦測試「獨立開啟遊戲（新分頁）」。手機橫向或小視窗建議使用獨立入口。
