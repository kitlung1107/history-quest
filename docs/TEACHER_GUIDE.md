## 新增或修改內容

### 新增的日常管理功能

教師後台右上角的「網站與教材管理」會進入 CMS。成績 PIN 與 CMS 的 GitHub 登入權限分開。

| CMS 項目                        | 可自行修改                                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 網站與首頁設定 → 網站與首頁區塊 | 網站名稱、副標題、英文名、標誌、大圖、報到標題、精選標題、沒有任務時的提示；主題卡片、每日一問、積分區塊的顯示開關 |
| 網站與首頁設定 → 首頁主題卡片   | 卡片名稱、簡介、符號、顏色、連結年級；拖動排序，最多六張                                                           |
| 網站與首頁設定 → 年級顯示及排序 | 中一至中六的顯示名稱、顯示開關及選單次序；拖動排序                                                                 |
| 年級與課題                      | 新增課題、修改名稱、所屬年級、排序、公開顯示                                                                       |
| 歷史任務                        | 原有教材欄位，以及所屬課題、公開顯示、首頁精選、顯示次序                                                           |

課題識別碼建立後請保持不變，改名稱只改「課題名稱」。任務年級會跟隨課題，改名或調整所屬年級不會改動任務識別碼，既有成績仍用原有任務識別碼對應。課題停用請用隱藏，避免刪除後留下無效任務連結。

新任務預設隱藏且不是首頁精選。公開任務、課題及年級三者都開啟時，學生才看得到。首頁只列精選任務；「全部」列出所有公開任務；課題按鈕會真正篩選該課題。次序數字越小越前，同數字按標題排列。隱藏只影響網站顯示，不是存取權限；不要把私人資料放進公開教材檔案。

「每日一問」目前是可修改的展示文字，不會自動每日更換或收集答案。主題卡片連到年級；隱藏年級會一併隱藏其主題卡片、課題及任務。

### 儲存、檢查與復原

儲存後會觸發 GitHub Actions。建置成功後重新整理正式網站，檢查首頁、課題選單及任務。系統會檢查課題連結、重複識別碼、必要欄位及答案範圍，錯誤會阻止新版發佈，原先已發佈的網站仍保留。首頁及任務編輯器可在儲存前預覽目前草稿及試答，其他內容使用目前建置版本；正式網站仍要等待發佈。

修改前可先記下原值或保存圖片。需要復原時可在 CMS 填回原值再儲存；較大範圍可由有儲存庫權限的人利用 GitHub 提交紀錄復原對應變更。復原同樣需要等待重新建置。請勿隨意更改已有任務的識別碼。

開發檢查：`pnpm check`、`pnpm test:content`、`pnpm build`。本機以 `pnpm dev` 啟動後，可用 `/?preview=student` 查看學生版面；此開發預覽不建立學生資料，請勿用來驗證成績提交。

登入網站 `/cms/` 後，選擇 **Sign in with Token**，再使用只限於 `history-quest` 儲存庫的 GitHub fine-grained personal access token 登入。選擇「歷史任務」後即可新增或修改內容。`task_id` 只可使用英文字母、數字、底線及連字號，發佈後不應更改，否則舊成績不再對應。新增／複製任務首次儲存會自動加入獨立後綴並隱藏；確認內容後再公開。完成編輯並發佈後，Sveltia CMS 會 Commit 至 `main`，GitHub Actions 隨即重新建置 GitHub Pages。詳細安全設定見 [內容管理登入方式](./CMS_ACCESS.md)。

## 影片與互動遊戲

YouTube 連結會轉換為 `youtube-nocookie.com` 嵌入網址；Google Drive 檔案連結會轉為預覽模式。HTML5／iframe 遊戲必須使用 HTTPS，而且來源網站需允許被 iframe 嵌入。遊戲 iframe 會套用 sandbox 權限限制，以減少第三方內容風險。

中五「冷戰世界」的《冷戰・地下檔案》保持獨立部署，更新及成績範圍見 [冷戰遊戲嵌入維護](./COLD_WAR_GAME.md)。

## 教師後台

前往 `/admin`，輸入交付時提供的教師 PIN。PIN 驗證在 GAS 執行，並非只以 JavaScript 隱藏畫面。成功後可檢視不重複學生、完成紀錄、任務分頁數量、平均分圖表及逐筆資料。

新版包含答案收集箱、成績與逐題答案 CSV 匯出、班級名單匯入及欠交比對、短答批改與評語。學生由「我的提交與評語」使用私人查閱碼查看結果。每次改題發佈後，重新整理教師後台並按「同步題目設定」。各項操作見 [八項新增功能與升級步驟](./TEACHING_UPGRADE.md)。

## 資料與私隱

網站會在學生裝置的 `localStorage` 保存班別、姓名、學號、任務進度與尚未送出的同步佇列。教師應依校本私隱政策告知學生資料用途、保留期及查詢方式；不再需要的成績分頁應由獲授權教師在試算表內處理。
